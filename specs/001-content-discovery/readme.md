# Episodic

Projeto desenvolvido para um trabalho da faculdade, utilizando **React** e o método **Spec-Kit (Spec-Driven Development)** para planejar e estruturar o desenvolvimento.

O projeto surgiu como uma proposta inspirada no **TV Time**, plataforma utilizada para acompanhar e descobrir filmes e séries, que encerrou suas atividades em julho de 2026.

Em vez de recriar toda a plataforma, o **Episodic** foca em um problema específico: **ajudar o usuário a decidir o que assistir**.

Para isso, o usuário responde a um pequeno quiz sobre suas preferências e recebe recomendações de filmes e séries. O projeto utiliza uma API externa para obter os dados dos títulos e aplica conceitos estudados em aula, como **componentização, Props, useState, useEffect, React Router e consumo de APIs**.
